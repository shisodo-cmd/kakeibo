# シンプル家計簿

収入管理を省いた、支出専用のスマホ向け家計簿MVPです。

## 機能
- 支出入力（日付、金額、店名・内容、カテゴリー、支払方法、メモ）
- 月ごとの支出合計・先月比
- カテゴリー別集計
- 履歴検索・カテゴリー/支払方法フィルター
- カテゴリー別・支払方法別の分析
- 支出削除
- localStorageによる端末内保存
- スマホ向けレスポンシブUI

## 起動
静的Webアプリなので、`index.html` をWebサーバーで公開するだけで動作します。
GitHub Pages / Netlify / Vercel等でも公開できます。

## データ
現段階では外部DBを使わず、ブラウザのlocalStorageに保存します。
ブラウザデータを削除すると家計簿データも消えるため、MVP確認用です。
